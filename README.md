## 📖 О проекте

**CoffeeCraft & TeaCraft by CyberOwl** — это полнофункциональное Progressive Web App (PWA) приложение с открытым исходным кодом, объединяющее две великие культуры осознанного заваривания: **спешелти-кофе третьей волны** и **китайскую чайную традицию Гунфу Ча**.

Приложение работает прямо в браузере, устанавливается как нативное приложение на смартфон или ПК, функционирует **100% оффлайн** без подключения к интернету и сохраняет все ваши дегустационные записи локально без регистрации и слежки.

## ✨ Ключевой функционал

Приложение оснащено переключателем **`[ ☕ Кофе | 🍵 Чай ]`**, который мгновенно адаптирует интерфейс, цветовую палитру, таймеры и базу знаний:

### ☕ Режим «Спешелти Кофе» (CoffeeCraft)

* **⏱️ Помощник заваривания и пошаговые таймеры:**
  * **Рожковая кофемашина (Эспрессо):** 9 бар, расчет Brew Ratio (1:1.5 ристретто, 1:2 нормаль, 1:2.5 спешелти, 1:3 лунго), фаза прединфузии и контроль времени пролива.
  * **V60 — Метод 4:6 Тэцу Касуя:** чемпионский рецепт World Brewers Cup 2016 для точной настройки сладости и плотности чашки.
  * **V60 — Рецепт Джеймса Хоффманна:** эталонный одинарный пуровер 60 г/л.
  * **AeroPress (Инвертированный метод):** иммерсия с полным контролем экстракции.
  * **Chemex (Кемекс):** рецепт для кристально чистой чашки без масел и осадка.
  * **French Press Хоффманна:** заваривание без продавливания плунжера до дна.
  * **Moka Pot (Гейзерная кофеварка):** преднагрев воды и отсечка охлаждением.
  * **Cold Brew & Джезва (Турка):** холодный концентрат и восточная классика.
* **📓 Дневник дегустаций зёрен:**
  * Сенсорный **6-осевой векторный радар** (Кислотность, Сладость, Чистота, Послевкусие, Тело, Горечь).
  * Интерактивное **колесо дескрипторов SCA (Specialty Coffee Association)**: ягоды, цитрусы, тропики, цветы, шоколад, специи, ферментация.
  * Учет терруара: страна, регион, высота, обработка (мытая, натуральная, анаэробная, хани), обжарщик и дата.
* **🍸 Анатомия напитков в бокале:**
  * Интерактивный поперечный срез чашки с визуализацией слоев (эспрессо, вспененное молоко, микропена, апельсиновый сок, тоник, пломбир).
  * Рецепты и калькулятор калорий/кофеина для: *Эспрессо, Флэт Уайт, Капучино, Латте, Кортадо, Бамбл Кофе, Эспрессо-тоник, Раф-кофе, Аффогато*.
  * Пересчет объема (150–350 мл) и типов молока (цельное, овсяное, миндальное, кокосовое, обезжиренное).
* **⚙️ Гид по помолу и физика экстракции:**
  * Шкала 7 фракций (от пудры <150 мкм до крупного >1400 мкм) с тактильными ориентирами.
  * Таблица кликов для популярных кофемолок: *Comandante C40 MK3/MK4, Timemore C2/C3, 1Zpresso K-Ultra, Kingrinder K6, Fellow Ode Gen 2, Baratza Encore*.
  * **SCA Калькулятор экстракции (TDS & Extraction Yield %)** с диагностикой недоэкстракции (<18%), золотого стандарта (18–22%) и переэкстракции (>22%).
  * Расчет точки закипания воды в зависимости от высоты над уровнем моря.

---

### 🍵 Режим «Чайная лаборатория» (TeaCraft)

* **🫖 Традиционные чайные таймеры:**
  * **Гунфу Ча (Пин Ча / Проливы в гайвани или типоте):** омовение листа $\rightarrow$ 1-й пролив (10с) $\rightarrow$ 2-й (12с) $\rightarrow$ 3-й (15с) $\rightarrow$ 4-й (25с) $\rightarrow$ 5-й (40с).
  * **Европейское настаивание в чайнике:** контроль экспозиции 3:00–4:00 мин.
  * **Матча (Традиционное взбивание Часен):** усутя 75°C со взбиванием W-движениями до изумрудной пены.
  * **Варка на живом огне по Лу Юю (VIII век):** фазы «крабьи глаза», «шум ветра в соснах», раскручивание воронки и танец чаинок.
  * **Cold Brew Tea:** холодная экстракция аминокислот без терпких танинов.
* **📓 Чайный дневник дегустаций:**
  * Специализированный китайский радар чая: **Аромат**, **Хуэй Гань** (сладкое возвратное послевкусие), **Ча Ци** (чайное состояние), **Плотность настоя**, **Свежесть**, **Терпкость**.
  * Коллекция знаменитых лотов: *Да Хун Пао, Дарджилинг Margaret's Hope FTGFOP1, Шу Пуэр Мэнхай 7572, Лун Цзин, ГАБА Алишань, Бай Хао Инь Чжэнь, Фэн Хуан Дань Цун Я Ши Сян*.
* **📖 Энциклопедия 6 великих категорий чая:**
  * *Зеленый (Люй Ча)*, *Белый (Бай Ча)*, *Улун (Цин Ча)*, *Красный (Хун Ча)*, *Пуэр и Хэй Ча*, *Матча*.
  * Иероглифы, пиньинь, степень ферментации, подходящая посуда и биохимия L-теанина.
* **💧 Чайная лаборатория воды и температуры:**
  * Интерактивный термометр заваривания (70°C – 100°C) с подсказками сортов.
  * Калькулятор минерализации воды (TDS ppm) и объяснение жесткости воды.
  * Стадии закипания по «Чайному Канону» Лу Юя.

## 📱 Установка как PWA (Progressive Web App)

Приложение CoffeeCraft поддерживает полную установку на мобильные устройства и десктоп:

* **Android (Chrome, Яндекс, Samsung Internet):**
  Нажмите кнопку **«Установить»** прямо в шапке сайта или выберите в меню браузера *«Установить приложение»*.
* **iOS (iPhone / iPad в Safari):**
  Нажмите кнопку **«Поделиться»** (иконка со стрелкой) $\rightarrow$ выберите **«На экран "Домой"»**.
* **Windows / macOS / Linux (Chrome / Edge):**
  Нажмите иконку установки в правой части адресной строки браузера или кнопку «Установить» в шапке.

> ✈️ **Оффлайн-режим:** После первой загрузки приложение кэшируется Service Worker'ом и работает в авиарежиме, в горах и в поездках без интернета.

## 🔒 Конфиденциальность и данные

* Никакой регистрации, учетных записей или сбора персональных данных.
* Все ваши рецепты, зёрна, чайные лоты и дегустационные заметки хранятся исключительно в вашем браузере (`LocalStorage`).
* Встроенная функция **«Экспорт»** и **«Импорт»** позволяет в один клик сохранить полную резервную копию дневника в файл `.json`.

## 💻 Локальная разработка

### Требования
* **Node.js 20+** или **Bun 1.2+**
* Менеджер пакетов `npm`, `pnpm` или `bun`

### Установка и запуск

1. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/Leonid-Perkin/coffeecraft.git
   cd coffeecraft
   ```

2. Установите зависимости:
   ```bash
   bun install
   # или npm install
   ```

3. Запустите сервер разработки:
   ```bash
   bun dev
   # или npm run dev
   ```

4. Откройте в браузере: `http://localhost:5173/`

### Сборка проекта
```bash
bun run build
# или npm run build
```

## 🚀 Развертывание на GitHub Pages

В репозитории уже настроен автоматический пайплайн **GitHub Actions** (`.github/workflows/deploy.yml`):
* Любой коммит в ветку `main` автоматически собирает проект и публикует его на GitHub Pages.
* Пути к ассетам сконфигурированы относительно (`base: './'`), что исключает любые ошибки 404 при хостинге в подпапках репозитория.
