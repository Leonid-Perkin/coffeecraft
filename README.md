# ☕ CoffeeCraft by CyberOwl — Спешелти компаньон для любителей кофе

**CoffeeCraft by CyberOwl** — современное, адаптивное веб-приложение для ценителей спешелти-кофе и бариста в тёплой кофейной палитре (эспрессо, обжаренные зёрна, карамель и крема).

---

## 🎨 Обновленный дизайн
* **Кофейная цветовая гамма:**
  * Глубокий темный фон свежесваренного эспрессо (`#140d09` – `#160e0a`) с теплым мягким амбиентным свечением кофейни.
  * Карточки и панели в оттенках обжарочного цеха (`#1c120c`, `#24150d`, `#382215`).
  * Акцентные золотисто-карамельные кнопки и бейджи крема (`#d48b46`, `#f5be7e`, `#f3be7a`).
  * Тёплый молочный текст цвета вспененного латте (`#fdf8f3`, `#ede2d3`, `#caa890`).

## 🚀 Развертывание на GitHub Pages

Приложение полностью адаптировано для публикации на **GitHub Pages** (настроены относительные пути `./assets/`, исключающие ошибки 404).

### Вариант 1. Автоматический деплой через GitHub Actions (Рекомендуемый)
В репозиторий уже добавлен готовый workflow: `.github/workflows/deploy.yml`.

1. Создайте репозиторий на GitHub и отправьте в него код:
   ```bash
   git init
   git add .
   git commit -m "feat: coffee app release"
   git branch -M main
   git remote add origin https://github.com/ВАШ_ЛОГИН/ВАШ_РЕПОЗИТОРИЙ.git
   git push -u origin main
   ```
2. В настройках вашего GitHub-репозитория откройте **Settings** $\rightarrow$ **Pages**.
3. В пункте **Source** выберите **GitHub Actions**.
4. Готово! GitHub Actions автоматически соберет проект и развернет его на `https://ВАШ_ЛОГИН.github.io/ВАШ_РЕПОЗИТОРИЙ/`.

### Вариант 2. Ручной деплой через `gh-pages`
В `package.json` уже настроены скрипты:
```bash
npm run deploy
# или
bun run deploy
```
Команда соберет проект и автоматически опубликует ветку `gh-pages`.
